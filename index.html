01 / SYSTEM DESIGN

Architecture built for control

The original React console calls FastAPI. A separate worker executes the existing LangGraph workflow; the API never runs agents directly.

React / TypeScriptWeb console
↓ REST / SSE ↑
FastAPIServices · API · validation
↓ durable jobs / events ↑
SQLiteJobs · checkpoints · locks · decisions
↓ worker claims job
Independent worker + LangGraphStateful orchestration · conditional routing
BeadsTickets & dependencies
Docker / Copilot CLIIsolated Git workspaces

Structured agent outputs

Specialized prompts and Pydantic validation keep handoffs explicit and machine-readable.

Observable execution

Persisted events, SSE, logs, reports and diffs expose progress and decisions.

Controlled recovery

Bounded correction loops, human checkpoint resume and explicit restart with archived attempts. Crash continuation is not implemented.

05 / GOVERNANCE & TRANSFERABILITY

Beyond code generation

Security by design

Separate Git clones, non-privileged Docker, restricted artifact access and token redaction. No automatic push or merge.

Human accountability

Approve or reject explicitly. Separate ticket, workflow and job statuses; persistent decisions and auditable evidence.

Enterprise applications

The same orchestration pattern could be adapted to document review, data quality and IT operations. These are potential use cases, not implemented features.
